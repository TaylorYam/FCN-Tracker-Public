## Project title

FCN Tracker — Structured Product Monitoring Platform

## Project description

Designed and built FCN Tracker, an interactive structured-product monitoring
platform that translates Fixed Coupon Note terms and multi-underlying price
paths into product-state monitoring and visualization.

The application models coupon schedules, observation periods, knock-out
conditions, strike levels, memory-KO behavior, and underlying performance,
presenting complex product terms through a user-oriented monitoring
interface.

Built with Next.js, React, TypeScript, and automated tests. The public
portfolio edition uses synthetic product terms and price data while
preserving the core financial logic and application architecture.
